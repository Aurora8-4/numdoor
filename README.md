# 神也过不了第二关（数字门）

抖音小程序跑酷小游戏：切跑道穿过「数字门」，让数字越滚越大，撞紫色 BOSS 门时数字必须够大。
第一关放慢热身，**第二关直接把速度和门槛拉起来**——所以叫这个名字。

## 两种形态，同一套逻辑

| 目录 | 说明 |
| --- | --- |
| `index.html` | **网页版**，单文件、零依赖，双击就能玩，手机竖屏体验最佳 |
| `抖音小程序/` | **抖音小程序工程**（原生 TTML/TTSS + Canvas 2D），导入抖音开发者工具即可编译、真机预览、上传 |

两个版本的玩法参数完全一致，改数值只需要改一处再同步。

## 玩法

- **切道**：`←` `→` / `A` `D`；手机**左右滑一下切一格**（一次手势只切一格），轻点则直接跳到对应跑道
- **数字门**：穿过就执行门上的运算 —— 青色 `+N`、金色 `×N`、红色 `-N` / `÷N`
- **BOSS 门**：门上是门槛（如 `≥14`），当前数字够就绿光「✓ 可击破」，不够当场结束
- 一行通常只有**一扇好门**，另外两扇是坑；偶尔有空的跑道

## 网页版怎么跑

```bash
# 直接双击 index.html，或者起个本地服务方便手机访问
node 本地预览服务器.js        # 默认 8080，会打印局域网地址
```

> 局域网地址只在同一 Wi-Fi 下有效；改动 `index.html` 后刷新即可，无需构建。

## 小程序怎么跑

1. 抖音开发者工具 → 导入 `抖音小程序/` 目录（含 `app.json` 的那一层）
2. `project.config.json` 里的 `appid` 换成你自己的 AppID
3. 编译 → 预览（扫码真机）→ 上传 → 开放平台提交审核

细节、适配点和参数表见 `抖音小程序/README.md`，发布步骤见 `发布清单.md`。

## 技术要点

- **伪 3D 透视**：`scale = NEAR / z`，地面 Y 与 `1/z` 线性映射，所以路面是严格透视正确的梯形，且世界里的直线在屏幕上是直线
- **手感**：切道用 90ms 内的定时补间（三次缓出），不是逐帧指数插值；输入做了「一次手势只切一格」的锁
- **小程序双通道**：优先取 `type="2d"` 画布节点（`width = 屏宽 × dpr` + `setTransform`），取不到时降级到 `tt.createCanvasContext` + `setInterval` 帧循环，两条通道共用同一套绘制代码
- **性能**：静态渐变缓存、帧内零 `setData`、`onHide` 暂停帧循环
